# Chat about a PDF

Attach a PDF (a contract, a manual, an invoice) and ask about it.

**Example:** you received `lease-agreement.pdf`, a 12-page flat rental contract, and want the points that matter
before you sign.

## What you need

- The PDF saved as a file. One you have open in a tab: save it first.
- For a scanned PDF (pictures of pages, no text), a model that takes images.

## What you type

Attach the file: paperclip → **File…**, or drop it on the message box. Then:

> Summarize this lease: who signs it, how long it lasts, the notice period, the deposit and any penalties, with the
> page of each.

## What you see

1. A chip with the file's name shows above the message box. Point at it to see how it will be sent:
   *PDF, 12 pages, 30,000 characters, sent as text*, or for a scanned one *PDF without text: 4 pages sent as images*.
2. The answer cites the pages, so you can check each point in the PDF.
3. Ask follow-up questions in the same conversation: the PDF stays with it.

## What you approve

Nothing: the file is yours, and reading it touches no website.

## If it goes wrong

- **A long PDF**: the model gets the start first, and reads on when it needs to. Ask about one part at a time
  (*"only the termination clauses"*) for the best answers.
- **A scanned PDF and *This model may not take images***: choose a model that takes images, or a PDF with text.
- **The PDF is refused**: password-protected and damaged files cannot be read, nor files over 20 MB.
- **You reopen the conversation later**: the PDF is kept by name only. Attach it again.
