# How-to guides

Short guides for things you can do with Teseo, each built around one example: what you need, what you type,
what you see, what you approve, and what to do if it goes wrong. New here? Start with
[Getting started](../guide/getting-started.md).

## Everyday tasks

| Guide | Example |
|---|---|
| [Fill in a form](fill-a-form.md) | Ask a shop for a quote through its contact form |
| [Compare products across tabs](compare-across-tabs.md) | Three laptops in three tabs, compared in one table |
| [Research with web search](research-the-web.md) | A museum's opening hours and prices, with sources |
| [Extract data into a table](extract-a-table.md) | Your order history, ready to paste into a spreadsheet |
| [Watch a page and continue](watch-a-page.md) | Download a report as soon as it is ready |
| [Ask about part of a page](ask-about-part-of-a-page.md) | Mark a chart on a dashboard and ask what it shows |
| [Chat about a PDF](chat-about-a-pdf.md) | The key points of a rental contract, with page numbers |
| [A one-click widget button](widget-button.md) | Translate the text you select on a news site |
| [Transcribe what a tab plays](transcribe-a-tab.md) | A 20-minute talk, corrected as you listen, then its key points |
